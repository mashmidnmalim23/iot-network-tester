מה הפרויקט עושה טופולוגיה תקינות ומפרט רכיבים יציאה

מה הפרויקט עושה?

כלי פיזי ייעודי מבוסס בקר ESP32 לביצוע ניטור, סריקת רשתות, מיפוי טופולוגיה ובדיקות עומס בסביבות ארגוניות.

תיאור כללי

המערכת היא כלי חומרה קטן ("Drop-Box") שמחברים לרשת ארגונית ומבצע בדיקות אבטחה ותקינות: סריקת פורטים, זיהוי רכיבים ומיפוי הרשת, ובדיקות עומס מבוקרות. המכשיר מתוכנת בשפת ++C/C ומדווח בזמן אמת לפלטפורמת Firebase, ושומר גיבוי מקומי של הממצאים במסד נתונים SQL לצורך הפקת דוחות (Forensics).

תכונות מרכזיות

סריקת רשת ופורטים

מיפוי אוטומטי וזיהוי רכיבים חיוניים ברשת, איתור כתובות IP ופורטים פתוחים לצורך בדיקת תקלות ובעיות ברשת.

Port & Network Scanning

מיפוי טופולוגיה

יצירת תמונת רשת מלאה – אילו רכיבים קיימים וכיצד הם מחוברים זה לזה, להצגה ויזואלית של הארגון.

Topology Mapping

בדיקות עומס

בדיקת עמידות הרשת בעזרת UDP/TCP Flooding – מדידת זמני תגובה (Latency) ואיבוד חבילות (Packet Loss) תחת עומס.

Stress Testing

שליטה בזמן אמת

שליחת פקודות וקבלת תוצאות בזמן אמת דרך Firebase – ניתן להפעיל את המכשיר ולראות ממצאים מרחוק.

Real-Time C&C

הגנה עצמית

המכשיר פועל בצורה שקטה (Stealth) ומזהה פתיחה/טלטול פיזי של הקופסה (Anti-Tamper) כדי למנוע חשיפה.

Anti-Tamper & Stealth

עבודה במצב Offline

במידה והרשת מנותקת, המכשיר שומר את הממצאים מקומית בכרטיס SD וממשיך לפעול – ומסנכרן כשהחיבור חוזר.

Offline Buffering

ארכיטקטורה טכנולוגית (Tech Stack)

  • שפת פיתוח: ++C / C (ב-Arduino IDE או VS Code עם PlatformIO)
  • פרוטוקולי תקשורת: SPI (ל-SD ולמודול הרשת), I2C ואנלוגי (לחיישנים)
  • ענן (זמן אמת): ספריית Firebase-ESP-Client + Firebase Realtime Database
  • מסד נתונים: SQL לשמירת ממצאים והפקת דוחות (Forensics)
