# IoT Network Tester – אתר הפרויקט

אתר סטטי (HTML + CSS בלבד, ללא JavaScript) שמציג את מסמך האפיון (PRD) של פרויקט
**IoT Network Tester** – מכשיר מבוסס ESP32 לניטור, סריקת רשתות, מיפוי טופולוגיה
ובדיקות עומס בסביבות ארגוניות.

## הדפים באתר

| קובץ | תיאור |
|------|-------|
| `login.html` | מסך התחברות (נקודת הכניסה) – ויזואלי בלבד |
| `overview.html` | מה הפרויקט עושה + התכונות המרכזיות |
| `topology.html` | טופולוגיית הרשת (מצוירת כולה ב-CSS) |
| `specs.html` | תקינות ומפרטי עבודה של הרכיבים |
| `components.html` | שמונה רכיבי החומרה |
| `style.css` | קובץ העיצוב המשותף לכל הדפים |

## איך מריצים

שומרים את כל הקבצים **באותה תיקייה** ופותחים את `login.html` בדפדפן.

## הערה על ההתחברות

מסך ההתחברות הוא **ויזואלי בלבד**. ללא JavaScript ושרת אי אפשר לאמת סיסמה –
כל לחיצה על "כניסה" מעבירה לדף הבית. לאבטחה אמיתית נדרש שרת שמאמת משתמשים.

## טכנולוגיות (לפי מסמך האפיון)

- **קושחה:** ‎++C / C (Arduino IDE / PlatformIO)
- **פרוטוקולים:** SPI, I2C, אנלוגי
- **ענן:** Firebase Realtime Database (Firebase-ESP-Client)
- **מסד נתונים:** SQL (לדוחות Forensics)
